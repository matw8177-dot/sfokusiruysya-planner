# Сфокусируйся — учебный планировщик

Небольшое приложение для учебных задач и Pomodoro. Это один HTML-файл: сборка, установка и сервер не нужны.

## Первый запуск

### Открыть как сайт

После включения GitHub Pages сайт будет доступен по адресу:

https://matw8177-dot.github.io/sfokusiruysya-planner/

Чтобы включить публикацию:

1. Откройте **Settings** репозитория.
2. В боковом меню выберите **Pages**.
3. В разделе **Build and deployment** установите **Source → GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь успешного запуска **Deploy to GitHub Pages**.
5. Вернитесь в **Settings → Pages** и откройте опубликованный адрес.

После этого каждый новый коммит в ветку `main` автоматически обновит сайт.

**Важно:** GitHub Pages доступен для публичных репозиториев на GitHub Free. Для публикации из приватного репозитория понадобится подходящий платный план GitHub. Если Pages не дает включить публикацию, оставьте репозиторий приватным и запустите приложение локально либо отдельно решите, готовы ли вы открыть репозиторий: при смене видимости публичными станут исходные файлы.

### Запустить на компьютере без публикации

В приватном репозитории откройте `index.html`, скачайте файл кнопкой **Download raw file** и откройте скачанный файл двойным щелчком. Он запустится в браузере без установки программ.

## Как пользоваться

- **Дедлайн:** измените название события и дату. Начальное значение даты — через 14 дней.
- **Таймер:** выберите «Учеба · 25 мин» или «Отдых · 5 мин», нажмите «Старт». Кнопка меняется на «Пауза»; «Сброс» начинает выбранный режим заново. По завершении звучит сигнал.
- **Задачи:** напишите задачу, выберите предмет и при необходимости отметьте срочность. Кнопка «Взять в фокус» закрепит задачу над таймером.
- **Выполнение:** нажмите квадрат рядом с задачей. Завершённые учебные сессии учитываются в счетчике за сегодня.
- **Данные:** дедлайн, задачи и счетчик сохраняются в localStorage браузера. Они доступны только в том же браузере и профиле, где вы пользовались приложением; между устройствами они не синхронизируются.

## Состав

- `index.html` — приложение, стили и JavaScript.
- `.github/workflows/deploy.yml` — публикация GitHub Pages при изменении ветки `main`.
